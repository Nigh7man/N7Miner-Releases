# N7Miner on HiveOS

Ready-to-import PearlHash Flight Sheets:

- [Kryptex](n7miner-kryptex.json)
- [HeroMiners](n7miner-herominers.json)
- [LuckyPool](n7miner-luckypool.json)

## Import

1. Add your PRL wallet in HiveOS under **Wallets**.
2. Open one of the JSON files above, click **Raw**, and copy the complete JSON.
3. In HiveOS open **Flight Sheets -> Import**, paste the JSON, and import it.
4. Select/confirm your PRL wallet and apply the Flight Sheet.

The Custom Miner installation URL points directly to the official N7Miner GitHub Release asset:

`https://github.com/Nigh7man/N7Miner-Releases/releases/download/v0.1.124-rc.1/n7miner-0.1.124_rc.1_universal_hive_x64.tar.gz`

The worker name is taken from `%WORKER_NAME%`. The imported sheet is pinned to release `v0.1.124-rc.1`.
