# N7Miner v0.1.139 — release notes

## Русский

**Изменения:**

- Небольшое улучшение энергоэффективности на NVIDIA Ampere (SM86 / RTX 30).
- Переработан алгоритм AutoOC: учёт подтверждённых неверных вычислений, корректировка нестабильного офсета и восстановление отдельных GPU.
- Исправления ошибок и повышение стабильности.

Комиссия разработчика: 1% (проверена по production-манифесту и self-check).
Пакеты: Windows x64, Linux x64 и HiveOS.

## English

**Changes:**

- Minor power-efficiency improvements on NVIDIA Ampere GPUs (SM86 / RTX 30 series).
- Reworked AutoOC tuning: verified wrong-result handling, unstable-offset correction and per-GPU recovery.
- Bug fixes and stability improvements.

Developer fee: 1% (verified in the production manifest and self-check).
Packages: Windows x64, Linux x64 and HiveOS.
