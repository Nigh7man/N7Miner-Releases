# CMP compute unlock — HiveOS

**[Русский](CMP-HIVEOS.md) · [English](CMP-HIVEOS.en.md)**

В **N7Miner 0.1.133** экспериментальный CMP compute unlock доступен в обычном пакете HiveOS. Майнер проверяет совместимость, скачивает пакет под точную версию NVIDIA Open и собирает модуль для установленного ядра.

**Установка и восстановление драйверного модуля могут потребовать перезагрузки рига.**

## Совместимость

- Проверка `--cmp check` допускает **CMP 40HX, 50HX, 70HX, 90HX** и отдельные варианты **CMP 170HX**.
- Для **CMP 50HX и 90HX** дополнительно проверяется **PCI subsystem**.
- Для **CMP 170HX** поддерживаются только версии NVIDIA Open `610.43.02`, `610.57.04` и `615.71.09`.
- Для **CMP 30HX** compute unlock **не предусмотрен**.

Для **Ubuntu 24.04 и 26.04** предусмотрен отдельный запуск через `n7miner-cmp.py`.

## Как включить в HiveOS

Команды добавляются в **Flight Sheet → Extra config arguments** обычного пакета N7Miner:

1. **Проверка без установки:** `--cmp check`.
2. **Включение:** замените команду на `--cmp unlock`. N7Miner скачает пакет под установленную точную версию NVIDIA Open, соберёт модуль под текущее ядро и попытается **перезагрузить риг**. Если автоматическая перезагрузка не удалась, дальнейшие действия появятся в **Event log**.
3. После перезагрузки проверьте видимость карт командой `nvidia-smi -L`.
4. **Возврат штатного модуля:** `--cmp restore` (при необходимости с перезагрузкой).
