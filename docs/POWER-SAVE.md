# Power Save — режим снижения энергопотребления NVIDIA

**[Русский](POWER-SAVE.md) · [English](POWER-SAVE.en.md)**

Power Save управляет дополнительным энергосберегающим профилем NVIDIA во время майнинга PearlHash. Параметр `--ps` также называется `--power-save`. Это отдельный механизм: он **не заменяет** ограничение мощности `--pl`, настройку памяти `--mclock` или AutoOC.

## Где доступен

- **Windows x64:** N7Miner 0.1.138, совместимая NVIDIA-карта и драйвер.
- **Linux x64 / HiveOS:** N7Miner 0.1.138, совместимая NVIDIA-карта, драйвер и права **`root`** для управления GPU.
- **AMD:** Power Save не поддерживается.

Функция зависит от модели GPU и драйвера. Наличие `--ps` в `--help` само по себе не доказывает аппаратную совместимость карты.

## Проверенные драйверы

**Power Save протестирован на драйверах NVIDIA:** HiveOS — `610.43.03`, `615.71.10`; Windows — `596.49`, `621.24`. Тестирование на этих версиях не гарантирует совместимость с каждой моделью видеокарты.

## Уровни

| Уровень | Назначение |
| --- | --- |
| `0` | Power Save выключен для выбранной карты. |
| `1` | Первый профиль энергосбережения. С него удобно начинать сравнение. |
| `2` | Второй профиль; на совместимых GPU использует более сильную настройку. |
| `3` | Третий профиль; на некоторых поколениях отличается от `2`, на других совпадает с ним. |

**Наибольший эффект Power Save в наших тестах наблюдался на RTX 50-й серии (например, RTX 5080).** Это не гарантия такого же выигрыша на каждой карте. **Уровни Power Save — номера профилей, а не проценты уменьшения потребления.** Для RTX 20/30/40 уровни `2` и `3` в текущей реализации используют одинаковую основную настройку; на RTX 50 они различаются. Реальные TH/s, Вт и TH/W зависят от видеокарты и драйвера. Повышение уровня не гарантирует рост эффективности.

## Как включить в Windows

Вставьте дополнительный параметр в команду запуска майнера:

```bat
n7miner.exe -a pearlhash -o prl-ru.kryptex.network:7048 -u YOUR_WALLET -w rig01 --devices 0 --ps 1
```

Замените `YOUR_WALLET` своим адресом. Здесь `--devices 0` выбирает NVIDIA GPU 0, а `--ps 1` включает первый уровень.

Для всех выбранных NVIDIA-карт:

```text
--ps 1
```

Для разных уровней по картам в порядке `--devices`:

```text
--devices 0,1,2 --ps 1,2,0
```

Таким образом GPU 0 получает уровень 1, GPU 1 — уровень 2, для GPU 2 Power Save отключён. Если указано несколько уровней, их количество должно совпадать с числом выбранных NVIDIA-карт. Эквивалентная полная форма — `--power-save 1`. Значение `4` и выше недопустимо.

## HiveOS / Linux

В HiveOS откройте **Flight Sheet → Extra config arguments** и добавьте:

```text
--ps 1
```

Это задаёт уровень 1 для выбранных NVIDIA-карт. Для нескольких карт используется список, например `--devices 0,1,2 --ps 1,2,0`.

В Linux добавьте тот же флаг к запуску `./n7miner`. Для изменения и восстановления драйверных параметров Power Save требуются права **`root`**. На неподдерживаемых драйверах или GPU применение может завершиться предупреждением.

## Power Save, Power Limit и AutoOC

Параметры выполняют разные задачи:

| Параметр | Назначение |
| --- | --- |
| `--ps 1` | Выбирает внутренний профиль Power Save. |
| `--pl 250` | Ограничивает мощность GPU значением 250 Вт. |
| `--pl 80%` | Задаёт 80% штатного Power Limit карты. |
| `--mclock 405` | Запрашивает лок памяти 405 МГц, если карта и драйвер поддерживаются. |
| `--autooc` | Автоматически подбирает смещение частоты ядра, если частота ядра зафиксирована. |

Использовать несколько режимов вместе можно на совместимых сборках, но лучше сперва измерить действие каждого по отдельности. Для проверки сравните хэшрейт, потребление и число принятых шар на одном и том же пуле после стабилизации работы.

## Что означает столбец PS

В TUI и обычном консольном режиме для каждой карты используются столбцы **`A`**, **`OFFSET`**, **`PS`**:

- **A** — состояние подбора AutoOC: `▲`, `~`, `▼`, `✓` или `!`.
- **OFFSET** — текущее смещение частоты ядра в МГц.
- **PS** — режим Power Save: зелёное число `1`/`2`/`3` означает применённый профиль; жёлтое — ожидание применения; красное `off` — режим отключён после неудачной попытки; `—` — режим не запрошен.

Надпись **AutoOC** в верхней строке TUI появляется, только когда включён `--autooc`. Сам Power Save от AutoOC не зависит.

## Если режим не применяется

Проверьте, что у вас подходящая сборка и совместимая NVIDIA-карта. Отдельные версии драйвера могут не поддерживать необходимое управление. При подтверждённом безопасном откате майнер продолжает майнить без Power Save, а в `PS` отображается `off`.

Майнер предусматривает восстановление изменённых параметров при корректном завершении. После аварийного завершения или перезапуска системы проверьте настройки GPU: принудительное завершение не всегда позволяет выполнить восстановление.
