# N7Miner v0.1.140 — release notes

## Русский

- Улучшены переключение на резервный пул и возврат на основной, учёт отправленных шар при изменении сложности.
- AutoOC: исправлен учёт ошибок видеокарт, исправлены повторные попытки восстановления и отдельные проблемы управления Power Save.

- Небольшие оптимизации энергоэффективности майнинга.
- Исправления мелких ошибок.

Комиссия разработчика: 1%. Пакеты: Windows x64, Linux x64 и HiveOS.
Ранее опубликованная таблица производительности относится к версии v0.1.138.

## English

- Improved failover to backup pools, return to the primary pool, and handling of submitted shares during difficulty changes.
- AutoOC: fixed GPU fault tracking, recovery retries, and specific Power Save control issues.

- Minor mining power-efficiency optimizations.
- Bug fixes.

Developer fee: 1%. Packages: Windows x64, Linux x64 and HiveOS.
Previously published performance measurements remain attributed to v0.1.138.
